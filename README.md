# Climate Prediction Website

A modern, animated website for climate prediction and weather analytics with interactive visualizations and AI-powered forecasting capabilities.

## Features

- **Animated Hero Section**: Eye-catching globe animation with particle effects
- **Climate Prediction Tool**: Interactive form for generating weather predictions
- **Data Visualizations**: Real-time charts showing climate trends
- **Responsive Design**: Fully responsive layout that works on all devices
- **Smooth Animations**: CSS animations and transitions throughout
- **Interactive Elements**: Hover effects, ripple animations, and scroll-triggered animations

## Technologies Used

- **HTML5**: Semantic markup and modern structure
- **CSS3**: Advanced animations, gradients, and responsive design
- **JavaScript**: Interactive functionality and data visualization
- **Chart.js**: Professional climate data charts
- **Font Awesome**: Icon library for UI elements

## File Structure

## Getting Started

1. Clone or download the project files
2. Open `index.html` in a web browser
3. The website will load with all features functional

## Customization

### Colors
Edit the CSS variables in `styles.css`:
```css
:root {
    --primary-color: #00d4ff;
    --secondary-color: #0099cc;
    --accent-color: #ff6b35;
    /* ... other variables */
}
```

### Animations
Modify animation keyframes in `styles.css` to adjust timing and effects.

### Data
Update the mock data generation in `script.js` to use real climate APIs.
